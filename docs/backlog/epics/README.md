# Epics

One `EPIC-NNN.md` per business objective. An epic groups stories under one concrete
objective — don't create a new epic per request if an existing one already covers it.
See [`../README.md`](../README.md) for the full workflow.

Template for `EPIC-NNN.md`:

```markdown
# EPIC-NNN: [Title]
- **Status:** proposed | in-progress | done | superseded by EPIC-NNN
- **Business objective:** [what impact, for which actor — one concrete sentence]
- **Stories:** US-NNN, US-NNN
```

Keep the business objective sentence concrete enough to reject stories that don't
serve it. "Improve the product" doesn't reject anything; "reduce time-to-first-clip
for a new IT operator" does.
